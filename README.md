# SAVORÉ — Restaurant Website

**SpireX Foundation — Task 18**

A responsive restaurant website built with **HTML, CSS, and JavaScript**.

## Features
- Modern responsive restaurant landing page
- Hero section with CTA buttons
- Interactive menu category filters
- Menu cards with pricing
- Our Story section
- Private dining, corporate events & Chef's Table services
- Responsive image gallery
- Functional table-booking interface with date validation
- Mobile navigation
- Responsive layout for desktop, tablet and mobile

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Unsplash image URLs

## Run locally
Open `index.html` in any modern browser.
